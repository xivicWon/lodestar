# Lodestar P5 — RDB → OWL v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PostgreSQL 스키마(라이브 JDBC 또는 DDL 스크립트)를 읽어 테이블→OWL클래스·컬럼→DataProperty·FK→ObjectProperty로 변환해 기존 온톨로지 엔진에 주입하고, 관계를 목록/패널로 표시한다.

**Architecture:** 두 입력 경로(`MetadataService`=라이브 DB, `DdlParser`=DDL 텍스트)가 순수 데이터 `SchemaModel`로 수렴 → `SchemaToOwlMapper`가 `OWLOntology` 생성 → `OntologyHolder.replace()`로 주입. 주입 후엔 기존 Class/Property 컨트롤러·추론·Turtle저장·프론트 편집이 전부 재사용된다. 신규 코드는 전부 새 패키지 `com.ontostudio.rdb`.

**Tech Stack:** Kotlin 2.1 / Spring Boot 3.4 / OWL API 5.5.0 / JSqlParser 4.9 / PostgreSQL JDBC / H2(테스트) / Vue 3 + TS + Pinia + Vitest.

## Global Constraints

- 온톨로지 범위는 **TBox only** — 행 데이터(개체/Individual)는 생성하지 않는다.
- 두 입력 경로는 **동일한 `SchemaModel`을 산출**해야 한다 (동치성).
- IRI 이름은 **결정론적** — 같은 스키마를 재임포트하면 같은 IRI가 나와야 한다 (dedup 카운터 사용 금지, 테이블/컬럼명은 유니크하다고 가정).
- 신규 백엔드 코드는 모두 패키지 `com.ontostudio.rdb` 아래.
- OWL API 스트림은 변경 전 `.toList()`로 반드시 구체화 (ConcurrentModificationException 회피) — 기존 코드 관례.
- 에러는 기존 `ApiException(status, error, message, targetIri)` + `ApiExceptionHandler`로 처리.
- 테스트 프레임워크: 백엔드 `kotlin.test`(+ JUnit5, `@SpringBootTest`/`@WebMvcTest`), 프론트 `vitest` + `@vue/test-utils`.

```kotlin
package com.ontostudio.rdb

private const val XSD = "http://www.w3.org/2001/XMLSchema#"

/** SQL 타입 문자열(길이/정밀도 파라미터 포함 가능)을 XSD 데이터타입 IRI로 매핑. 미지의 타입은 xsd:string. */
fun sqlTypeToXsd(sqlType: String): String {
    val t = sqlType.trim().lowercase().substringBefore('(').trim()
    return when {
        t.contains("char") || t.contains("text") || t.contains("clob") -> XSD + "string"
        t.contains("bool") -> XSD + "boolean"
        t.startsWith("timestamp") || t.startsWith("datetime") -> XSD + "dateTime"
        t == "date" -> XSD + "date"
        t.startsWith("time") -> XSD + "time"
        t.contains("int") || t == "serial" || t == "bigserial" -> XSD + "integer"
        t.contains("numeric") || t.contains("decimal") || t.contains("real") ||
            t.contains("double") || t.contains("float") || t == "money" -> XSD + "decimal"
        else -> XSD + "string"
    }
}
```

```kotlin
package com.ontostudio.rdb

import org.semanticweb.owlapi.apibinding.OWLManager
import org.semanticweb.owlapi.model.IRI
import org.semanticweb.owlapi.model.OWLOntology
import org.springframework.stereotype.Component

/** SchemaModel → OWLOntology (TBox only). 무상태: 매 호출마다 새 manager/ontology 생성. */
@Component
class SchemaToOwlMapper {

    /** IRI-안전 슬러그: 공백→_, 문자/숫자/_ 이외 제거. 결정론적(카운터 없음). */
    internal fun slug(name: String): String =
        name.trim().replace(Regex("\\s+"), "_").replace(Regex("[^\\p{L}\\p{N}_]"), "").ifBlank { "x" }

    internal fun classIri(base: String, table: String): IRI = IRI.create(base + slug(table))
    internal fun dataPropIri(base: String, table: String, column: String): IRI =
        IRI.create(base + slug(table) + "." + slug(column))

    fun build(schema: SchemaModel, baseIri: String): OWLOntology {
        val mgr = OWLManager.createOWLOntologyManager()
        val df = mgr.owlDataFactory
        val ont = mgr.createOntology()

        for (table in schema.tables) {
            val cls = df.getOWLClass(classIri(baseIri, table.name))
            mgr.addAxiom(ont, df.getOWLDeclarationAxiom(cls))
            mgr.addAxiom(ont, df.getOWLAnnotationAssertionAxiom(
                cls.iri, df.getOWLAnnotation(df.rdfsLabel, df.getOWLLiteral(table.name))))
            if (table.primaryKey.isNotEmpty()) {
                mgr.addAxiom(ont, df.getOWLAnnotationAssertionAxiom(
                    cls.iri, df.getOWLAnnotation(df.rdfsComment,
                        df.getOWLLiteral("PK: " + table.primaryKey.joinToString(", ")))))
            }

            // FK 컬럼은 DataProperty로 중복 생성하지 않는다 (Task 4에서 ObjectProperty로 승격)
            val fkColumns = table.foreignKeys.flatMap { it.fkColumns }.toHashSet()
            for (col in table.columns) {
                if (col.name in fkColumns) continue
                val dp = df.getOWLDataProperty(dataPropIri(baseIri, table.name, col.name))
                mgr.addAxiom(ont, df.getOWLDeclarationAxiom(dp))
                mgr.addAxiom(ont, df.getOWLAnnotationAssertionAxiom(
                    dp.iri, df.getOWLAnnotation(df.rdfsLabel, df.getOWLLiteral(col.name))))
                mgr.addAxiom(ont, df.getOWLDataPropertyDomainAxiom(dp, cls))
                mgr.addAxiom(ont, df.getOWLDataPropertyRangeAxiom(
                    dp, df.getOWLDatatype(IRI.create(sqlTypeToXsd(col.sqlType)))))
            }
        }
        return ont
    }
}
```

```kotlin
package com.ontostudio.rdb

import net.sf.jsqlparser.parser.CCJSqlParserUtil
import net.sf.jsqlparser.statement.create.table.CreateTable
import net.sf.jsqlparser.statement.create.table.ForeignKeyIndex
import org.springframework.stereotype.Component

/** DDL 텍스트 → SchemaModel. CREATE TABLE 만 처리하고, 파싱 실패 구문은 조용히 건너뛴다. */
@Component
class DdlParser {

    fun parse(sql: String): SchemaModel {
        val tables = mutableListOf<TableInfo>()
        // ';' 기준으로 개별 문장 분리 후 하나씩 파싱 → 트리거/함수 등 미지원 구문은 건너뛴다.
        for (raw in sql.split(";")) {
            val stmt = raw.trim()
            if (stmt.isEmpty()) continue
            val parsed = try { CCJSqlParserUtil.parse(stmt) } catch (e: Exception) { null } ?: continue
            if (parsed is CreateTable) tables.add(toTableInfo(parsed))
        }
        return SchemaModel(tables)
    }

    private fun unquote(s: String): String = s.trim().trim('"', '`', '[', ']')

    private fun toTableInfo(ct: CreateTable): TableInfo {
        val tableName = unquote(ct.table.name)
        val columns = (ct.columnDefinitions ?: emptyList()).map { cd ->
            val specs = (cd.columnSpecs ?: emptyList()).joinToString(" ").uppercase()
            ColumnInfo(unquote(cd.columnName), cd.colDataType.dataType, nullable = !specs.contains("NOT NULL"))
        }

        val pk = mutableListOf<String>()
        val fks = mutableListOf<ForeignKeyInfo>()

        // 1) 컬럼 인라인 제약: "PRIMARY KEY", "REFERENCES table(col)"
        for (cd in ct.columnDefinitions ?: emptyList()) {
            val specs = (cd.columnSpecs ?: emptyList()).joinToString(" ")
            val up = specs.uppercase()
            if (up.contains("PRIMARY KEY")) pk.add(unquote(cd.columnName))
            val m = Regex("REFERENCES\\s+([\\w\"`.]+)\\s*\\(\\s*([\\w\"`]+)\\s*\\)", RegexOption.IGNORE_CASE).find(specs)
            if (m != null) {
                fks.add(ForeignKeyInfo(
                    listOf(unquote(cd.columnName)),
                    unquote(m.groupValues[1].substringAfterLast('.')),
                    listOf(unquote(m.groupValues[2]))))
            }
        }

        // 2) 테이블-레벨 제약: getIndexes() 에 PRIMARY KEY / ForeignKeyIndex 로 등장
        for (idx in ct.indexes ?: emptyList()) {
            if (idx is ForeignKeyIndex) {
                fks.add(ForeignKeyInfo(
                    idx.columnsNames.map { unquote(it) },
                    unquote(idx.table.name),
                    (idx.referencedColumnNames ?: emptyList()).map { unquote(it) }))
            } else if (idx.type?.uppercase()?.contains("PRIMARY KEY") == true) {
                idx.columnsNames.forEach { pk.add(unquote(it)) }
            }
        }

        return TableInfo(tableName, columns, pk.distinct(), fks)
    }
}
```

> **참고:** JSqlParser의 `ForeignKeyIndex`/`Index`/`CreateTable` API 접근자 이름이 버전에 따라 다를 수 있다. Step 4에서 테스트가 실패하면 실제 4.9 API에 맞춰 접근자(`columnsNames`, `referencedColumnNames`, `table.name` 등)를 조정하라 — 매핑 로직 자체는 유지.

```kotlin
package com.ontostudio.rdb

import org.springframework.stereotype.Service
import java.sql.Connection

/** JDBC Connection → SchemaModel. DatabaseMetaData 표준 API만 사용(드라이버 무관). */
@Service
class MetadataService {
    private val systemSchemas = setOf("information_schema", "pg_catalog", "pg_toast")

    fun extract(conn: Connection): SchemaModel {
        val md = conn.metaData
        val catalog = conn.catalog
        val tables = mutableListOf<TableInfo>()

        // (schema, table) 목록 수집
        val ids = mutableListOf<Pair<String?, String>>()
        md.getTables(catalog, null, "%", arrayOf("TABLE")).use { rs ->
            while (rs.next()) {
                val schem = rs.getString("TABLE_SCHEM")
                if (schem != null && schem.lowercase() in systemSchemas) continue
                ids.add(schem to rs.getString("TABLE_NAME"))
            }
        }

        for ((schem, name) in ids) {
            val columns = mutableListOf<ColumnInfo>()
            md.getColumns(catalog, schem, name, "%").use { rs ->
                while (rs.next()) {
                    columns.add(ColumnInfo(
                        rs.getString("COLUMN_NAME"),
                        rs.getString("TYPE_NAME"),
                        rs.getInt("NULLABLE") == java.sql.DatabaseMetaData.columnNullable))
                }
            }

            val pk = sortedMapOf<Int, String>()
            md.getPrimaryKeys(catalog, schem, name).use { rs ->
                while (rs.next()) pk[rs.getInt("KEY_SEQ")] = rs.getString("COLUMN_NAME")
            }

            // FK: FK_NAME 별로 묶고 KEY_SEQ 순서 유지
            val fkCols = linkedMapOf<String, sortedMapOf<Int, String>().javaClass>() // placeholder; replaced below
            val fkBuild = linkedMapOf<String, Triple<String, java.util.TreeMap<Int, String>, java.util.TreeMap<Int, String>>>()
            md.getImportedKeys(catalog, schem, name).use { rs ->
                while (rs.next()) {
                    val fkName = rs.getString("FK_NAME") ?: "${name}_${rs.getString("FKCOLUMN_NAME")}"
                    val entry = fkBuild.getOrPut(fkName) {
                        Triple(rs.getString("PKTABLE_NAME"), java.util.TreeMap(), java.util.TreeMap())
                    }
                    val seq = rs.getInt("KEY_SEQ")
                    entry.second[seq] = rs.getString("FKCOLUMN_NAME")
                    entry.third[seq] = rs.getString("PKCOLUMN_NAME")
                }
            }
            val foreignKeys = fkBuild.values.map {
                ForeignKeyInfo(it.second.values.toList(), it.first, it.third.values.toList())
            }

            tables.add(TableInfo(name, columns, pk.values.toList(), foreignKeys))
        }
        return SchemaModel(tables)
    }
}
```

```kotlin
package com.ontostudio.rdb

import com.ontostudio.core.OntologyHolder
import com.ontostudio.core.OntologyMapper
import com.ontostudio.dto.OntologyMetaDto
import org.springframework.web.bind.annotation.*

data class DdlImportRequest(val sql: String, val schemaName: String? = null)

@RestController
@RequestMapping("/api/rdb")
class RdbImportController(
    private val dbConnector: DbConnector,
    private val metadataService: MetadataService,
    private val ddlParser: DdlParser,
    private val schemaMapper: SchemaToOwlMapper,
    private val holder: OntologyHolder,
    private val ontologyMapper: OntologyMapper
) {
    private fun ingest(schema: SchemaModel, dbName: String): OntologyMetaDto {
        val baseIri = "http://lodestar/rdb/${schemaMapper.slug(dbName)}#"
        val ont = schemaMapper.build(schema, baseIri)
        holder.replace(ont, baseIri)
        return ontologyMapper.meta()
    }

    @PostMapping("/import/ddl")
    fun importDdl(@RequestBody req: DdlImportRequest): OntologyMetaDto =
        ingest(ddlParser.parse(req.sql), req.schemaName ?: "schema")

    @PostMapping("/import/connection")
    fun importConnection(@RequestBody info: ConnectionInfo): OntologyMetaDto =
        dbConnector.open(info).use { conn -> ingest(metadataService.extract(conn), info.database) }
}
```

```vue
<script setup lang="ts">
import { computed } from 'vue'
import { useOntologyStore } from '../stores/ontologyStore'

const store = useOntologyStore()

function short(iri: string | null): string {
  if (!iri) return '—'
  const hash = iri.split('#').pop() ?? iri
  return hash.split('/').pop() ?? hash
}

const rows = computed(() => store.objectProperties.map(p => ({
  iri: p.iri,
  label: p.label ?? short(p.iri),
  domain: p.domains.map(short).join(', ') || '?',
  range: p.ranges.map(short).join(', ') || '?',
  related: !!store.selectedIri &&
    (p.domains.includes(store.selectedIri) || p.ranges.includes(store.selectedIri)),
})))

const sorted = computed(() => [...rows.value].sort((a, b) => Number(b.related) - Number(a.related)))
</script>

<template>
  <div class="relations-panel">
    <h3>관계 (테이블 간)</h3>
    <p v-if="rows.length === 0" class="empty">관계가 없습니다.</p>
    <ul v-else class="relation-list">
      <li v-for="r in sorted" :key="r.iri" class="relation-row" :class="{ related: r.related }">
        <span class="dom">{{ r.domain }}</span>
        <span class="arrow">→</span>
        <span class="rng">{{ r.range }}</span>
        <span class="lbl">{{ r.label }}</span>
      </li>
    </ul>
  </div>
</template>
```
