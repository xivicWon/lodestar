# P3 Reasoner Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** HermiT 추론기를 붙여 일관성 검사 + 추론된 subclass 계층을 계산하고, 프론트에서 "추론 실행"으로 일관성 배지와 트리 inferred 엣지를 눈으로 확인.

**Architecture:** 백엔드 `ReasonerService`가 요청 시 `holder.ontology`에 HermiT `OWLReasoner`를 생성해 `isConsistent()` + 추론된 직접 상위(asserted 제외)를 계산, `POST /api/reason`으로 반환(온톨로지 비침습). 프론트 store가 결과를 보관하고 툴바 버튼/일관성 배지/트리 inferred 오버레이로 표시.

**Tech Stack:** Backend Kotlin/Spring Boot + OWL API 5.5.0 + **HermiT** (`net.sourceforge.owlapi:org.semanticweb.hermit`). Frontend Vue 3 + Pinia + Vitest.

## Global Constraints

- 백엔드는 `backend/`, 프론트는 `frontend/`. 기존 P1/P2 코드 패턴 준수.
- 엔티티 식별자는 IRI(string). 추론은 `holder.ontology` 대상, `synchronized(holder.lock)`.
- 추론기는 온톨로지에 **쓰지 않는다**(계산만). reasoner는 사용 후 `dispose()`.
- REST 베이스 `/api`. 에러 계약 `{error, message, targetIri?}`.
- OWL API 5.5.0과 HermiT 버전 호환 필수 — 충돌 시 owlapi 5.5.0이 우선되도록.
- 프론트 백엔드 연결은 기존 Vite 프록시(`/api`→8090). 새 백엔드 무관 코드 미수정.
- TDD: 실패 테스트 → 실패 확인 → 최소 구현 → 통과 확인 → 커밋.

```kotlin
package com.ontostudio.reasoner

import com.ontostudio.core.OntologyHolder
import com.ontostudio.dto.InferredEdgeDto
import com.ontostudio.dto.ReasonResultDto
import org.semanticweb.HermiT.ReasonerFactory
import org.semanticweb.owlapi.reasoner.OWLReasoner
import org.springframework.stereotype.Service

@Service
class ReasonerService(private val holder: OntologyHolder) {

    fun reason(): ReasonResultDto = synchronized(holder.lock) {
        val reasoner: OWLReasoner = ReasonerFactory().createReasoner(holder.ontology)
        try {
            val consistent = reasoner.isConsistent
            if (!consistent) {
                val unsat = reasoner.unsatisfiableClasses.entities()
                    .filter { !it.isOWLNothing && !it.isOWLThing }
                    .map { it.iri.toString() }.toList()
                ReasonResultDto(false, unsat, emptyList())
            } else {
                ReasonResultDto(true, emptyList(), emptyList()) // inferred edges: Task 2
            }
        } finally {
            reasoner.dispose()
        }
    }
}
```

```kotlin
    private fun inferredEdges(reasoner: OWLReasoner): List<InferredEdgeDto> {
        val ont = holder.ontology
        val edges = mutableListOf<InferredEdgeDto>()
        ont.classesInSignature().filter { !it.isOWLThing && !it.isOWLNothing }.toList().forEach { c ->
            val asserted = ont.subClassAxiomsForSubClass(c).toList()
                .map { it.superClass }.filter { !it.isAnonymous }
                .map { it.asOWLClass() }.toSet()
            reasoner.getSuperClasses(c, true).entities().toList()
                .filter { !it.isOWLThing && !it.isOWLNothing }
                .forEach { sup ->
                    if (sup != c && sup !in asserted && ont.containsClassInSignature(sup.iri)) {
                        edges.add(InferredEdgeDto(c.iri.toString(), sup.iri.toString()))
                    }
                }
        }
        return edges
    }
```
