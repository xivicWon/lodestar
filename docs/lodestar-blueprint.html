ERD조차 없는 레거시 데이터베이스를 읽어, 숨은 구조·비즈니스 의미·관계를 AI가 이해하는 지식(온톨로지)으로 복원한다. 유저 페르소나: Prospector(탐광자).

서비스 청사진 · 2026-07-03 · 리포 코드네임 onto-studio

◆ 운영 모델 — 추론·확정·성장 루프

① 추론 (제안)

AI가 의미·관계 제안

암호 같은 테이블/컬럼 → 비즈니스 라벨·관계 후보. 정답표 없이 N회 반복추론의 합의율이 신뢰도.

② 승인 (세이브포인트)

운영자가 확정 → 고정

승인 시 온톨로지 라벨 반영 + 별도 저장소에 원자적 영속. 확정은 사람이 결정.

③ 그라운딩

확정 위에서 다음 추론

미확정만 추정하되 확정 사실을 앵커로 주입 → AI가 확정 맥락에 일관되게 확장.

④ 재임포트 병합

재스캔해도 유지

스키마가 바뀌어 재임포트해도 IRI 매칭으로 확정 라벨 자동 복원, 미매칭은 보존.

↻ 추론은 제안일 뿐 — 확정은 사람이 하고, 확정된 지식 위에서 시스템이 성장한다.
