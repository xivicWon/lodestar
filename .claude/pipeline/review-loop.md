# 로컬 리뷰-응답 루프 (Local Review-Response Loop)

PR 생성 후 AI 리뷰가 (지연 후) 작성되면, **메인 세션**이 이 루프로 대응한다.
핵심 원칙: **AI 리뷰를 그대로 따르지 않는다.** 로컬 fan-out 리뷰로 **더 넓은 시야에서 수정 방향을 독립 판정**한 뒤 움직인다.

---

## 0. 진입
- 트리거: PR에 `AI 코드 리뷰 완료` 코멘트가 새로 달림(모니터가 감지).
- 대상 PR 번호와 이슈 번호를 확정한다.

## 1. 라운드 카운트 & 상한 (사용자 규칙 3)
- `round` = 해당 PR의 `AI 코드 리뷰 완료` 코멘트 수.
- **상한 = 5.** `round > 5`면 **HALT**(§4) — 자동 수정 중단, 사람 에스컬레이션. 절대 더 돌리거나 강행 머지하지 않는다.

## 2. 로컬 fan-out 리뷰 (수정 방향 결정 *전* — 사용자 규칙 1)
입력 = {AI 리뷰 본문, `gh pr diff`, 관련 머지 계약(I1 #94·answer-shape #103 등), 이슈 수용기준}.
**독립 서브에이전트 K개를 병렬**로 띄운다(각자 다른 렌즈, 서로 안 봄). 각 리뷰어 산출:
- 진짜 이슈(파일:라인, severity), AI 리뷰의 **오탐(false positive)**, 권고 = `FIX` | `COMMENT_ONLY`, 근거.

메인이 종합 → **수정 필요 여부 + 수정 방향**을 넓은 시야에서 확정(AI 리뷰의 오탐은 버리고, 놓친 것은 추가).

### 강도 에스컬레이션 (push할수록 강하게 — 사용자 규칙 3)
| round | 리뷰어 K | 렌즈(누적) |
|---|---|---|
| 1 | 2 | 정확성/로직 · 계약 일관성 |
| 2 | 2 | + "직전 수정이 실제로 해소했나 · 회귀" |
| 3 | 3 | + 엣지케이스 · adversarial(refute) |
| 4 | 4 | + 교차 산출물/타 이슈 일관성(머지된 계약과 대조) |
| 5 | 4 + 1 | + 메타: "수익 체감 · 지금 멈춰야 하나" 판정 |

- 렌즈는 **누적**한다(라운드 오를수록 넓고 깊게).
- 서브에이전트 방식: 각 리뷰어에게 diff·리뷰·계약을 주고 **먼저 근거를 수집(read)한 뒤 판정**하게 한다(준비 후 리뷰).

## 3. 분기
- **`COMMENT_ONLY`** (종합 결과 코드 수정 불필요) → PR에 답변 코멘트 게시 → **승인·머지** → 정리(worktree/세션) → **다음 작업 착수**. (사용자 규칙 2)
- **`FIX`** (수정 필요) → 로컬 종합의 **수정 방향**을 브리프로 써서 cmux 세션에 지시 → 세션이 수정·push → 재리뷰 대기 → `round+1`로 §1부터 반복. (사용자 규칙 1)

## 4. HALT (round > 5)
자동 루프 종료. **머지·강행 금지.** 다음을 사람에게 보고: 라운드 이력, 남은 쟁점, 마지막 fan-out 종합, 권고(수동 결정/설계 재검토). 이후는 사람 판단.

## 경계
- 승인=머지는 **비-사소(다회 수정) 케이스에선 사람 승인**을 받는다(정답·정책 성격이면 특히). `COMMENT_ONLY` 단순 케이스만 자동 승인(규칙 2).
- Gold/정책/정답 성격 이슈(#99류)는 fan-out가 "정답은 사람" 판정을 내면 즉시 사람 에스컬레이션.

## 도구 연계
- **§1 라운드 카운트·상한(5)·발산 판정·HALT** → `review-round-governor` 스킬(내용 dedup 으로 ID 재부여 착시 제거).
- **§2 fan-out 리뷰어 = 오탐 필터** → 지적마다 `adversarial-finding-verifier` 에이전트(반증 우선). AI 리뷰의 오탐을 코드로 기각.
- **품질 게이트 확인** → `evidence-gate-runner` 에이전트(변경 범위→게이트 매트릭스). "리뷰 만족"이 아니라 게이트 그린이 종료 근거.
- **gold/정답 성격 지적** → `gold-oracle-guard` 스킬(자기승인·순환·축분리) 후 오라클 에스컬레이션.
