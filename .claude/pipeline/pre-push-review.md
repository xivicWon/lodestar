# push 전 자체 코드리뷰·검증 루프 (Pre-Push Self Review)

**워커 세션**이 커밋을 push 하기 **전에** 자기 변경(diff)을 스스로 리뷰·검증하는 단계.
목적: 결함을 push 이후 AI 리뷰 루프로 몰지 않고 **소스에서 먼저 잡는다**(#115 폭주의 구조적 예방).

> 이건 push **이전** · **워커 자신**이 도는 루프다. push **이후** · **메인 세션**이 AI 리뷰에 대응하는 `review-loop.md` 와 다르다(둘은 상보).

---

## 0. 진입
- 트리거: 구현·TDD 가 끝나 커밋까지 마쳤고, 이제 push 하려는 시점.
- 대상 = 이 브랜치가 `origin/main` 대비 만든 전체 diff(`git diff origin/main...HEAD`) + 미커밋 변경.

## 1. 6개 렌즈 리뷰 (범위: 이번 변경 diff)
아래 렌즈로 변경을 점검한다. 가능하면 **렌즈별 서브에이전트를 병렬**로 띄워 넓은 시야로(각자 근거를 먼저 읽고 판정). 소규모 변경이면 단일 다중렌즈 검토로 갈음.

| 렌즈 | 보는 것 |
|---|---|
| **버그** | 로직 오류·경계조건·널/예외·경쟁·리소스 누수·오프바이원 |
| **보안** | 입력검증·주입·비밀/PII 노출·권한·안전한 기본값·역직렬화 |
| **성능** | 불필요 반복/할당·N+1·복잡도·핫패스·대용량 입력 거동 |
| **유지보수** | 가독성·명명·중복·죽은 코드·응집/결합·테스트 용이성 |
| **SOLID** | SRP·OCP·LSP·ISP·DIP 위반, 과결합/추상화 누락 |
| **호환성** | 공개 계약/스키마/DB·API 하위호환, 마이그레이션, 의존/버전, 크로스엔진 패리티 |

각 findings: `파일:라인 · 렌즈 · severity(blocking/major/minor) · 근거 · 권고`.

## 2. 분류 — 이 이슈의 수정범주인가?
findings 를 두 갈래로 나눈다.

- **범주 안 (IN-SCOPE)** = 이번 변경이 도입했거나 직접 건드린 결함, 이 이슈 수용기준과 직결.
  → **고친다.**
- **범주 밖 (OUT-OF-SCOPE)** = 기존(pre-existing) 결함 · 무관한 서브시스템 · 대규모 리팩터 · 정책/설계 판단 · 다른 계약 소관.
  → **고치지 않는다.** 대신:
  1. PR(또는 이슈)에 **코멘트**로 근거와 함께 남기고,
  2. **후속 GitHub 이슈로 등록**(`gh issue create`, 적절한 라벨·마일스톤, 근거 파일:라인·이 PR 참조).

> 판단 기준: "이 변경을 되돌리면 그 결함도 사라지는가?" 그렇다면 IN-SCOPE. 아니면 OUT-OF-SCOPE.

## 3. 수정 → 재리뷰 루프 (최대 3회)
- IN-SCOPE 를 수정한다(가능하면 실패 테스트 추가 후 수정 — TDD).
- **재리뷰**: 바뀐 부분과 직전 findings 가 실제로 해소됐는지 + 회귀 없는지 재점검(해당 렌즈 중심).
- `round+1`. **상한 3.**
  - 3회 안에 IN-SCOPE blocking/major 가 모두 해소되면 → §4.
  - **3회 후에도 남으면**: 남은 것을 **OUT-OF-SCOPE 처리로 전환**(코멘트 + 후속 이슈)하고 진행한다. 무한히 돌지 않는다.

## 4. 게이트 & push
- 품질 게이트 그린: backend `./gradlew test` · frontend `npx vitest run && npx vue-tsc -b` · (스크립트/문서는 해당 검증기).
- 자체리뷰 통과(IN-SCOPE blocking/major 0) + 게이트 그린 → **push**.
- push 후 `gh pr create`. PR 본문에 **자체리뷰 요약**(렌즈별 결과, 수정 N건, 후속 이슈 M건) 포함.

## 도구 연계 (권장)
- **6렌즈 findings 오탐 필터** → `adversarial-finding-verifier` 에이전트(각 finding 1건씩, 반증 우선). 그럴듯한 오탐이 잘못된 수정을 부르지 않게.
- **3회 상한·내용 dedup·발산 판정** → `review-round-governor` 스킬. ID 재부여로 인한 "재발 0 착시"를 내용 기준으로 잡는다.
- **§4 게이트 실행** → `evidence-gate-runner` 에이전트(변경 범위→게이트 매트릭스).
- **gold/** 를 건드리면 → `gold-oracle-guard` 스킬(자기승인·순환·축분리) 먼저.

## 경계
- 이 이슈가 애초에 이 수정범주에 **부적합**(예: 문서 단독·정책 판단)이면 6렌즈 중 해당 없는 것은 건너뛰고, 발견은 전부 코멘트+후속이슈로 넘긴다.
- gold/정답/정책 성격 변경은 자체리뷰가 판단을 내리지 말고 **메인 세션·오라클**에 넘긴다(자기승인 금지).
- 상한(3회)은 **하드 규칙**이다. 초과 강행 금지 — 남은 건 후속 이슈.
